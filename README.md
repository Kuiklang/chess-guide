# หมากรุกไกด์ (Chess Guide)

เว็บแอปหมากรุกสากลภาษาไทย ใช้บนมือถือได้ มี 3 โหมด

- **เล่นกับบอท**: บอท Stockfish 5 ระดับ เลือกฝ่ายขาว ดำ หรือสุ่ม มีปุ่มขอคำใบ้
- **เล่น 2 คน**: ผลัดกันเดินบนเครื่องเดียว
- **โหมดไกด์**: ใช้ข้างกระดานจริง เลือกฝ่ายของคุณ แล้วกดเดินแทนฝั่งตรงข้าม โปรแกรมจะเสนอ 3 ทางเลือก (⭐ คือดีที่สุด) พร้อมเหตุผล และหลังคุณเดินจะอธิบายว่าตานั้นดีหรือพลาดอย่างไร

หลังจบเกมกด **วิเคราะห์เกม** เพื่อดูเกรดทุกตา กราฟความได้เปรียบ ความแม่นยำของแต่ละฝ่าย และคำอธิบายตาที่ดีกว่า เกมล่าสุด 20 เกมถูกเก็บไว้ในเบราว์เซอร์ และส่งออกเป็นไฟล์ PGN ได้

## พัฒนา

```bash
npm install
npm run dev      # เปิดที่ http://localhost:5173
npm test         # ทดสอบระบบอธิบาย
npm run build    # สร้างไฟล์ใน dist/
```

ทุกครั้งที่ push เข้า `main` GitHub Actions จะ build และเอาขึ้น GitHub Pages ให้อัตโนมัติ

## โครงสร้าง

- `src/lib/engine.ts` ตัวเชื่อมกับ Stockfish (web worker)
- `src/lib/explain.ts` ระบบอธิบายภาษาไทยแบบกฎ (ส้อม, ตรึง, กินฟรี, พัฒนาหมาก ฯลฯ) และการให้เกรด
- `src/lib/analysis.ts` วิเคราะห์ทั้งเกม
- `src/screens/` หน้าจอต่าง ๆ
